OPCIÓN 1: ABRIR PROYECTO EXISTENTE
  1. Visual Studio → File → Open → Project/Solution
  2. Seleccionar: Hospital_Santa_barbara_Proyecto.sln
  3. Presionar: Open
  4. Presionar: F5 (o Ctrl+Shift+B para compilar)
  5. Presionar: Ctrl+F5 para ejecutar sin debug


OPCIÓN 2: RECREAR DESDE CERO
  1. Seguir instrucciones en: COMO_CREAR_PROYECTO.txt
  2. Copiar archivos .h y .cpp
  3. Configurar propiedades de proyecto
  4. Compilar y ejecutar


PRIMEROS PASOS AL EJECUTAR:
  1. Aparecerá LoginForm
  2. Escribir: DOC001
  3. Escribir: 1234
  4. Presionar: Ingresar
  5. Se abrirá DoctorMainForm
  6. Explorar los botones del sidebar
  7. Presionar: Cerrar Sesión para volver a login
