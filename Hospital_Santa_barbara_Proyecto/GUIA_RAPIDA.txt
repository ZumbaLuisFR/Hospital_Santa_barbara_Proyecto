===============================================================================
					PASOS PARA USAR EL SISTEMA
===============================================================================

PASO 1: EJECUTAR LA APLICACIÓN
  1. Abrir Visual Studio
  2. Ir a: File → Open → Project/Solution
  3. Navegar a: Hospital_Santa_barbara_Proyecto.sln
  4. Presionar F5 (Debug) o Ctrl+F5 (Sin debug)
  5. Aparecerá la [LoginForm]

PASO 2: INICIAR SESIÓN (Ejemplo como Doctor)
  1. En "ID": Escribir DOC001
  2. En "Contraseña": Escribir 1234
  3. Presionar botón [Ingresar]
  4. Se abrirá [DoctorMainForm]

PASO 3: EXPLORAR EL PORTAL
  - Verá un header azul con "Hospital Santa Bárbara"
  - A la izquierda hay un panel lateral (sidebar) con opciones
  - En el centro se muestra el contenido

PASO 4: USAR LOS BOTONES DEL SIDEBAR
  Ejemplo como Doctor:
  - [Mis Pacientes]: Muestra lista de pacientes
  - [Historial]: Muestra historial médico
  - [Emitir Recetas]: Muestra recetas emitidas
  - etc.

PASO 5: CAMBIAR DE SECCIÓN
  - Simplemente presione otro botón en el sidebar
  - El contenido del ListBox se actualiza automáticamente
  - No es necesario cambiar de formulario

PASO 6: CERRAR SESIÓN
  - Presione [Cerrar Sesión] en la parte inferior del sidebar
  - Volverá a la [LoginForm]
  - Puede iniciar con otro usuario

PASO 7: SALIR DEL SISTEMA
  - En [LoginForm], presione [Salir]
  - Se cerrará la aplicación completamente

===============================================================================
					SOLUCIÓN DE PROBLEMAS
===============================================================================

PROBLEMA: La aplicación no compila
SOLUCIÓN:
  1. Verificar que Visual Studio esté actualizado
  2. Verificar que .NET Framework 4.8 esté instalado
  3. Limpiar solución: Build → Clean Solution
  4. Reconstruir: Build → Rebuild Solution

PROBLEMA: No puedo compilar con C++/CLI
SOLUCIÓN:
  1. Ir a: Tools → Get Tools and Features
  2. Modificar Visual Studio
  3. Seleccionar: "Desktop development with C++"
  4. Asegurarse que "C++/CLI support" esté marcado

PROBLEMA: Al presionar "Ingresar", nada sucede
SOLUCIÓN:
  1. Verificar que haya ingresado un ID (no déjelo vacío)
  2. Verificar que haya ingresado una contraseña
  3. Revisar que la contraseña sea "1234" para datos de prueba
  4. Verificar en la consola de debug si hay errores

PROBLEMA: El LoginForm no aparece en la pantalla
SOLUCIÓN:
  1. Verificar que Program.cpp tenga: Application::Run(gcnew LoginForm())
  2. Verificar que LoginForm.h esté en el proyecto
  3. Compilar nuevamente

PROBLEMA: Los datos no se actualizan cuando cambio de botón
SOLUCIÓN:
  1. Esto es normal - el sistema muestra datos de ejemplo
  2. Para agregar más datos, edite EmployeeData.h en el constructor
  3. Agregue más pacientes, citas o recetas en las listas

PROBLEMA: Recibo error LNK1104
SOLUCIÓN:
  1. Cerrar todas las instancias de la aplicación
  2. Ir a: Build → Clean Solution
  3. Esperar 10 segundos
  4. Ir a: Build → Rebuild Solution


===============================================================================
				  CÓMO AGREGAR MÁS DATOS
===============================================================================

Para agregar un nuevo DOCTOR:

  1. Abrir: EmployeeData.h
  2. En el constructor de HospitalData(), después del último doctor, agregar:

	 Doctor^ doc3 = gcnew Doctor();
	 doc3->id = L"DOC003";
	 doc3->nombre = L"Nombre del Doctor";
	 doc3->contrasena = L"1234";
	 doc3->especialidad = L"Especialidad";
	 doctores->Add(doc3);

  3. Guardar y compilar (Ctrl+Shift+B)
  4. Ahora puede iniciar sesión con DOC003


Para agregar un nuevo PACIENTE:

  1. Abrir: EmployeeData.h
  2. En el constructor de HospitalData(), después del último paciente, agregar:

	 Patient^ pac2 = gcnew Patient();
	 pac2->id = L"PAC002";
	 pac2->nombre = L"Nombre del Paciente";
	 pac2->email = L"email@correo.com";
	 pac2->telefono = L"555-1234";
	 pac2->direccion = L"Dirección";
	 pac2->contrasena = L"1234";
	 pacientes->Add(pac2);

  3. Guardar y compilar
  4. Puede iniciar sesión con PAC002 o crear uno nuevo automáticamente


Para agregar una nueva CITA:

  1. Abrir: EmployeeData.h
  2. En el constructor de HospitalData(), después de la última cita, agregar:

	 Appointment^ cita2 = gcnew Appointment();
	 cita2->idPaciente = L"PAC001";
	 cita2->nombrePaciente = L"Nombre del Paciente";
	 cita2->doctor = L"Nombre del Doctor";
	 cita2->fecha = L"2024-01-20";
	 cita2->hora = L"14:30";
	 cita2->razon = L"Razón de la consulta";
	 citas->Add(cita2);

  3. Guardar y compilar
  4. Al iniciar sesión como paciente, verá la cita en "Mis Citas"
