===============================================================================
			CÓMO CREAR EL PROYECTO EN VISUAL STUDIO DESDE CERO
===============================================================================

Si desea recrear este proyecto desde cero en Visual Studio, siga estos pasos:

===============================================================================
					PASO 1: CREAR PROYECTO NUEVO
===============================================================================

1. Abrir Visual Studio Community 2026 (o versión compatible)
2. Seleccionar: File → New → Project
3. En la búsqueda, escribir: "CLR"
4. Seleccionar: "CLR Empty Project (.NET Framework)"
5. Presionar: Next
6. Configurar:
   - Project name: Hospital_Santa_barbara_Proyecto
   - Location: C:\Users\USUARIO\source\repos\
   - Solution name: Hospital_Santa_barbara_Proyecto
   - Framework: .NET Framework 4.8
7. Presionar: Create

===============================================================================
					PASO 2: AGREGAR WINDOWS FORMS
===============================================================================

1. En Solution Explorer (lado derecho)
2. Click derecho en el proyecto
3. Seleccionar: Add → Existing Item
   (Si no hay esta opción, primero ir a: Properties → Linker → Subsystem → Windows)
4. Navegar a: \Windows\System32
5. Seleccionar: System.Windows.Forms.dll
   (Si pide, también seleccionar: System.Drawing.dll)

O alternativamente:
1. Click derecho en proyecto → Properties
2. Ir a: Linker → Subsystem
3. Cambiar a: Windows (/SUBSYSTEM:WINDOWS)
4. Ir a: VC++ Directories → Include Directories
5. Agregar: rutas del .NET Framework si es necesario

===============================================================================
					PASO 3: CREAR LOS ARCHIVOS .H
===============================================================================

En Solution Explorer:
1. Click derecho en proyecto
2. Seleccionar: Add → New Item
3. Seleccionar: Header File (.h)
4. Nombrar: EmployeeData.h
5. Copiar el contenido de EmployeeData.h (del proyecto entregado)
6. Repetir para cada archivo:
   - LoginForm.h
   - DoctorMainForm.h
   - NurseMainForm.h
   - PatientMainForm.h
   - RoleSelectionForm.h

===============================================================================
					PASO 4: CREAR LOS ARCHIVOS .CPP
===============================================================================

En Solution Explorer:
1. Click derecho en proyecto
2. Seleccionar: Add → New Item
3. Seleccionar: C++ File (.cpp)
4. Crear estos archivos (inicialmente vacíos o con includes):

EmployeeData.cpp:
   #include "EmployeeData.h"

LoginForm.cpp:
   #include "LoginForm.h"

DoctorMainForm.cpp:
   #include "DoctorMainForm.h"

NurseMainForm.cpp:
   #include "NurseMainForm.h"

PatientMainForm.cpp:
   #include "PatientMainForm.h"

RoleSelectionForm.cpp:
   #include "RoleSelectionForm.h"

Program.cpp: (Ver contenido en el proyecto entregado)
   (Contiene el main entry point)

===============================================================================
					PASO 5: CONFIGURAR PROPIEDADES
===============================================================================

1. Click derecho en proyecto → Properties
2. Ir a: Configuration Properties → General
3. Verificar:
   - Platform Toolset: v143 (o versión actual)
   - .NET Target Framework Version: v4.8

4. Ir a: C/C++ → General
5. Agregar en: Additional Include Directories:
   - C:\Program Files\Microsoft Visual Studio\2022\Community\VC\include

6. Ir a: Linker → Input
7. Agregar en: Additional Dependencies:
   - System.lib
   - System.Windows.Forms.lib
   - System.Drawing.lib

8. Ir a: Linker → Subsystem
9. Cambiar a: Windows (/SUBSYSTEM:WINDOWS)

10. Presionar: Apply y OK

===============================================================================
					PASO 6: COMPILAR PROYECTO
===============================================================================

1. Presionar: Ctrl+Shift+B (Rebuild Solution)
2. Observar Output window para errores
3. Si hay errores de "missing include", verificar que todos los .h estén presentes
4. Si hay errores de "undefined reference", verificar los archivos .cpp

Si la compilación es exitosa, pasamos al siguiente paso.

===============================================================================
					PASO 7: EJECUTAR APLICACIÓN
===============================================================================

1. Presionar: F5 (Debug) o Ctrl+F5 (Sin debug)
2. Aparecerá la ventana de [LoginForm]
3. Probar con credenciales de prueba:
   - ID: DOC001
   - Contraseña: 1234
   - Presionar: Ingresar

Si funciona correctamente, ¡el proyecto está listo!

===============================================================================
					SOLUCIÓN DE PROBLEMAS COMUNES
===============================================================================

PROBLEMA: "Error C0000" - Proyecto no se abre
SOLUCIÓN:
  1. Verificar que la carpeta .sln esté en el directorio correcto
  2. Intentar: File → Recent → y seleccionar el proyecto
  3. Si no aparece, cerrar VS y abrir de nuevo

PROBLEMA: "Error LNK1104" - No se puede crear ejecutable
SOLUCIÓN:
  1. Cerrar todas las instancias de la aplicación
  2. Build → Clean Solution
  3. Esperar 10 segundos
  4. Build → Rebuild Solution

PROBLEMA: "Error C2059" - Error de sintaxis en .h
SOLUCIÓN:
  1. Verificar que los #include estén al inicio del archivo
  2. Verificar que no haya caracteres especiales en los nombres
  3. Eliminar líneas en blanco o comentarios que causen conflicto

PROBLEMA: "Error C2664" - No se puede convertir argumento
SOLUCIÓN:
  1. Verificar que se esté usando String^ (no String)
  2. Verificar que los tipos coincidan en los argumentos
  3. Revisar el archivo que llama la función

PROBLEMA: LoginForm se muestra pero no responde a clics
SOLUCIÓN:
  1. Verificar que el archivo Program.cpp contenga:
	 [STAThreadAttribute]
	 int main(array<String^>^ args)
	 {
		 Application::EnableVisualStyles();
		 Application::SetCompatibleTextRenderingDefault(false);
		 LoginForm^ form = gcnew LoginForm();
		 Application::Run(form);
		 return 0;
	 }
  2. Recompilar

PROBLEMA: No puedo compilar en C++/CLI
SOLUCIÓN:
  1. Ir a: Tools → Get Tools and Features
  2. Modificar Visual Studio
  3. En "Desktop development with C++", marcar "C++/CLI support"
  4. Esperar a que se instale y reiniciar Visual Studio

PROBLEMA: Llama a Forms que no existen
SOLUCIÓN:
  1. Verificar que todos los .h estén en el proyecto
  2. Verificar que los #include estén correctamente escritos
  3. Revisar los nombres de las clases (sensible a mayúsculas)

PROBLEMA: Error "CS0234" - Namespace no encontrado
SOLUCIÓN:
  1. En C++/CLI, usar: using namespace System::Windows::Forms;
  2. Verificar que Windows Forms esté instalado en VS

===============================================================================
					PERSONALIZACIÓN DEL PROYECTO
===============================================================================

Para cambiar colores:

1. En DoctorMainForm.h, buscar:
   this->panelHeader->BackColor = System::Drawing::Color::FromArgb(0, 102, 204);

2. Cambiar los valores RGB (0, 102, 204) por otros, ej:
   - Rojo: (255, 0, 0)
   - Verde: (0, 255, 0)
   - Azul: (0, 0, 255)
   - Personalizados: (R, G, B)

3. Hacer lo mismo en NurseMainForm.h y PatientMainForm.h

Para cambiar el título:

1. En LoginForm.h, buscar:
   this->labelTitulo->Text = L"Hospital Santa Bárbara";

2. Cambiar por otro nombre, ej:
   L"Clínica San Juan"

3. Hacer lo mismo en DoctorMainForm.h, NurseMainForm.h, PatientMainForm.h

Para agregar nuevos datos:

1. En EmployeeData.h, en el constructor, agregar:
   Doctor^ doc3 = gcnew Doctor();
   doc3->id = L"DOC003";
   doc3->nombre = L"Nuevo Doctor";
   doc3->contrasena = L"1234";
   doc3->especialidad = L"Especialidad";
   doctores->Add(doc3);

2. Recompilar (Ctrl+Shift+B)
