===============================================================================
		 GUÍA DE INSTALACIÓN Y CONFIGURACIÓN DEL PROYECTO
===============================================================================

## PASO 1: REQUISITOS PREVIOS

Windows 10 o 11
Visual Studio Community 2026 (con C++ CLI instalado)
.NET Framework (versión 4.6 o superior)

## PASO 2: CREAR PROYECTO NUEVO EN VISUAL STUDIO

1. Abrir Visual Studio
2. Click en "Crear un proyecto"
3. Buscar "CLR" en el cuadro de búsqueda
4. Seleccionar "CLR Class Library (.NET Framework)" - C++
5. Click "Siguiente"
6. Nombre del proyecto: Hospital_Santa_barbara_Proyecto
7. Ubicación: C:\Users\USUARIO\source\repos\ (o donde prefieras)
8. Click "Crear"

## PASO 3: CAMBIAR TIPO DE PROYECTO A APLICACIÓN WINDOWS

1. Click derecho en el proyecto → Propiedades
2. Ir a Configuration Properties → General
3. Cambiar "CLR Support" a "CLR (/clr)"
4. Cambiar "Project Defaults" → "Managed Application":
   - Seleccionar "Windows Forms Application (/clr:safe)"
5. Aplicar cambios

## PASO 4: AGREGAR ARCHIVOS AL PROYECTO

1. Descargar/copiar todos los archivos .h y .cpp
2. Click derecho en Proyecto → Agregar → Elemento Existente
3. Seleccionar:
   - EmployeeData.h
   - LoginForm.h
   - LoginForm.cpp
   - DoctorMainForm.h
   - DoctorMainForm.cpp
   - NurseMainForm.h
   - NurseMainForm.cpp
   - PatientMainForm.h
   - PatientMainForm.cpp
   - RoleSelectionForm.h
   - RoleSelectionForm.cpp
   - Program.cpp
   - Hacer clic en "Agregar"

## PASO 5: CONFIGURAR PUNTO DE ENTRADA

1. Click derecho en Proyecto → Propiedades
2. Ir a Configuración Properties → Vinculador
3. En "Sistema":
   - Subsistema: Windows (/SUBSYSTEM:WINDOWS)
4. En "Punto de entrada":
   - Dejar vacío (Visual Studio lo detectará automáticamente)
5. Aplicar cambios

## PASO 6: ELIMINAR ARCHIVOS INNECESARIOS

1. Si existen archivos anteriores (mainForm.h, MenuForm.h, etc.)
2. Click derecho → Eliminar
3. Confirmar eliminación

## PASO 7: COMPILAR PROYECTO

1. Presionar Ctrl + Shift + B (o Compilar → Compilar Solución)
2. Esperar a que se complete la compilación
3. Verificar que no haya errores en la ventana de Errores

## PASO 8: EJECUTAR APLICACIÓN

1. Presionar F5 (o Depuración → Iniciar depuración)
2. La aplicación se abrirá con la pantalla de LoginForm
3. Probar con las credenciales:
   - Doctor: DOC001 / 1234
   - Enfermero: ENF001 / 1234
   - Paciente: PAC001 / 1234

## TROUBLESHOOTING

ERROR: "No se puede encontrar el archivo"
- Solución: Verificar que todos los archivos .h estén en la carpeta del proyecto

ERROR: "error LNK1104"
- Solución: Cerrar la aplicación en ejecución y compilar nuevamente

ERROR: "error C2144: syntax error"
- Solución: Verificar que los includes estén correctos
- Verificar que no falten llaves (}) al final de los archivos .h

ERROR: "error C2065: 'nombre identificador' no está declarado"
- Solución: El archivo no está incluido
- Agregar #include correctamente en el archivo necesario

ERROR: "error C2059: error de sintaxis: 'token'"
- Solución: Verificar que no haya caracteres especiales corruptos
- Copiar/pegar el contenido nuevamente
