					  FLUJO DE AUTENTICACIÓN
===============================================================================

ENTRADA: ID y Contraseña

┌─────────────────────────────────────────────────────────────┐
│ 1. Validar que campos no estén vacíos                       │
│    Si vacío → Mostrar error en labelError (rojo)            │
│              → Retornar                                      │
└─────────────────────────────────────────────────────────────┘
						   ▼
┌─────────────────────────────────────────────────────────────┐
│ 2. ¿AutenticarDoctor(ID, Contraseña)?                      │
│                                                              │
│    BuscarDoctor(ID) → if (doc->contrasena == Contraseña)   │
│    SÍ → Ir a paso 5                                         │
│    NO → Continuar                                           │
└─────────────────────────────────────────────────────────────┘
						   ▼
┌─────────────────────────────────────────────────────────────┐
│ 3. ¿AutenticarEnfermero(ID, Contraseña)?                   │
│                                                              │
│    BuscarEnfermero(ID) → if (enf->contrasena == Contraseña)│
│    SÍ → Ir a paso 6                                         │
│    NO → Continuar                                           │
└─────────────────────────────────────────────────────────────┘
						   ▼
┌─────────────────────────────────────────────────────────────┐
│ 4. ¿AutenticarPaciente(ID, Contraseña)?                    │
│                                                              │
│    BuscarPaciente(ID) → if (pac->contrasena == Contraseña) │
│    SÍ → Ir a paso 7                                         │
│    NO → Ir a paso 8                                         │
└─────────────────────────────────────────────────────────────┘
						   ▼
┌─────────────────────────────────────────────────────────────┐

						   ▼
┌─────────────────────────────────────────────────────────────┐
│ 6. ES ENFERMERO                                             │
│    • usuarioActual = ID                                     │
│    • rolActual = "Enfermero"                                │
│    • Crear NurseMainForm()                                  │
│    • Hide() LoginForm                                       │
│    • Show() NurseMainForm                                   │

===============================================================================
						FUNCIONES PRINCIPALES
===============================================================================

LOGINFORM.H:
  • buttonIngresar_Click() → Ejecuta flujo de autenticación
  • buttonSalir_Click() → Application::Exit()

DOCTORMAINFORM.H:
  • buttonPacientes_Click() → Actualiza ListBox con pacientes[]
  • buttonHistorial_Click() → Actualiza ListBox con historialMedico[]
  • buttonDiagnostico_Click() → MessageBox (placeholder)
  • buttonTratamiento_Click() → MessageBox (placeholder)
  • buttonRecetas_Click() → Actualiza ListBox con recetas[]
  • buttonCerrarSesion_Click() → Limpiar y close()

NURSEMAINFORM.H:
  • buttonPacientes_Click() → Actualiza ListBox con pacientes[]
  • buttonSignosVitales_Click() → MessageBox (placeholder)
  • buttonObservaciones_Click() → MessageBox (placeholder)
  • buttonEstado_Click() → MessageBox (placeholder)
  • buttonCerrarSesion_Click() → Limpiar y close()

PATIENTMAINFORM.H:
  • buttonDatos_Click() → Muestra información personal
  • buttonCitas_Click() → Muestra citas del paciente
  • buttonRecetas_Click() → Muestra recetas del paciente
  • buttonHistorial_Click() → Muestra historial médico
  • buttonSolicitarCita_Click() → MessageBox (placeholder)
  • buttonCerrarSesion_Click() → Limpiar y close()

EMPLOYEEDATA.H:
  • BuscarDoctor(id) → Busca en doctores[], retorna Doctor^ o nullptr
  • BuscarEnfermero(id) → Busca en enfermeros[], retorna Nurse^ o nullptr
  • BuscarPaciente(id) → Busca en pacientes[], retorna Patient^ o nullptr
  • AutenticarDoctor(id, pwd) → Valida contraseña
  • AutenticarEnfermero(id, pwd) → Valida contraseña
  • AutenticarPaciente(id, pwd) → Valida contraseña
  • CrearPacienteTemporal(id, pwd) → Crea Patient^ y agrega a lista
