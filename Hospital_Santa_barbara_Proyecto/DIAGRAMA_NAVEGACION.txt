===============================================================================
					COMPORTAMIENTO DE BOTONES
===============================================================================

BOTONES DE NAVEGACIÓN EN SIDEBAR:

Doctor:
  [Mis Pacientes]      → Carga lista de pacientes en ListBox
  [Historial]          → Carga historial médico en ListBox
  [Registrar Diag.]    → Muestra MessageBox de placeholder
  [Registrar Trat.]    → Muestra MessageBox de placeholder
  [Emitir Recetas]     → Carga lista de recetas en ListBox
  [Cerrar Sesión]      → Limpia variables y cierra form

Enfermero:
  [Pacientes]          → Carga lista de pacientes en ListBox
  [Signos Vitales]     → Muestra MessageBox de placeholder
  [Observaciones]      → Muestra MessageBox de placeholder
  [Actualizar Estado]  → Muestra MessageBox de placeholder
  [Cerrar Sesión]      → Limpia variables y cierra form

Paciente:
  [Mis Datos]          → Carga datos personales del paciente
  [Mis Citas]          → Filtra y carga citas del paciente
  [Mis Recetas]        → Filtra y carga recetas del paciente
  [Historial]          → Filtra y carga historial del paciente
  [Solicitar Cita]     → Muestra MessageBox de placeholder
  [Cerrar Sesión]      → Limpia variables y cierra form


===============================================================================
					ORDEN DE EJECUCIÓN DEL SISTEMA
===============================================================================

1. START
   ↓
2. [Program.cpp] - Punto de entrada
   ├─ Application::EnableVisualStyles()
   ├─ Application::SetCompatibleTextRenderingDefault(false)
   ├─ LoginForm^ form = gcnew LoginForm()
   └─ Application::Run(form)
   ↓
3. [LoginForm] - Se muestra
   ├─ Usuario ingresa ID
   ├─ Usuario ingresa Contraseña
   ├─ Presiona "Ingresar"
   └─ Ejecuta: buttonIngresar_Click()
   ↓
4. Validación en LoginForm::buttonIngresar_Click
   ├─ Si es Doctor → Busca en HospitalData::doctores
   │  └─ AutenticarDoctor(id, pwd) → DoctorMainForm
   ├─ Si es Enfermero → Busca en HospitalData::enfermeros
   │  └─ AutenticarEnfermero(id, pwd) → NurseMainForm
   ├─ Si es Paciente → Busca en HospitalData::pacientes
   │  └─ AutenticarPaciente(id, pwd) → PatientMainForm
   └─ Si no existe → CrearPacienteTemporal() → PatientMainForm
   ↓
5. Abre formulario correspondiente
   ├─ DoctorMainForm
   ├─ NurseMainForm
   └─ PatientMainForm
   ↓
6. Usuario interactúa con botones
   ├─ Cambio dinámico de contenido
   ├─ ListBox se actualiza
   └─ Funcionalidades se ejecutan
   ↓
7. Presiona "Cerrar Sesión"
   ├─ HospitalData::usuarioActual = ""
   ├─ HospitalData::rolActual = ""
   ├─ Form cierra
   └─ Vuelve a LoginForm
   ↓
8. Puede volver a iniciar sesión
   └─ Vuelve al paso 3
   ↓
9. Presiona "Salir" en LoginForm
   ├─ Application::Exit()
   └─ STOP


===============================================================================
					  FLUJO DE DATOS
===============================================================================

HospitalData (Datos Centralizados)
	│
	├─→ [Doctores] ────→ LoginForm → DoctorMainForm
	│
	├─→ [Enfermeros] ──→ LoginForm → NurseMainForm
	│
	├─→ [Pacientes] ───→ LoginForm → PatientMainForm
	│                         │
	│                         └─→ CrearPacienteTemporal()
	│
	├─→ [Citas] ────────→ PatientMainForm / DoctorMainForm
	│
	├─→ [Recetas] ──────→ PatientMainForm / DoctorMainForm
	│
	└─→ [Historial] ────→ PatientMainForm / DoctorMainForm

Cada formulario accede a HospitalData mediante:
	- HospitalData::usuarioActual (ID actual)
	- HospitalData::rolActual (Rol actual)
	- HospitalData::BuscarXXX() (Búsquedas)
	- HospitalData::AutenticarXXX() (Validaciones)
	- HospitalData::CrearPacienteTemporal() (Registro)


===============================================================================
					MANEJO DE SESIONES
===============================================================================

Variables Globales en HospitalData:
	└─ usuarioActual: String^ = ""
	└─ rolActual: String^ = ""

Al Iniciar Sesión:
	1. HospitalData::usuarioActual = "DOC001" (ejemplo)
	2. HospitalData::rolActual = "Doctor"
	3. PatientMainForm accede a estos valores:
	   └─ BuscarPaciente(usuarioActual) para obtener sus datos

Al Cerrar Sesión:
	1. HospitalData::usuarioActual = ""
	2. HospitalData::rolActual = ""
	3. Form se cierra y LoginForm queda disponible


===============================================================================
					PUNTOS CLAVE DEL DISEÑO
===============================================================================

✓ Separación por Rol:
  Cada rol tiene su propio formulario con interfaz personalizada

✓ Datos Centralizados:
  HospitalData es clase estática con todos los datos y métodos

✓ Sin Base de Datos:
  Usa List<T> de .NET para almacenamiento en memoria

✓ Navegación Clara:
  Sidebar con botones que cambiar contenido dinámicamente

✓ Filtrado de Datos:
  PatientMainForm filtra datos por usuarioActual

✓ Validación en LoginForm:
  Determina el rol y abre el formulario apropiado

✓ Colores Distintivos:
  Azul (Doctor), Verde (Enfermero), Azul Pastel (Paciente)

✓ Responsabilidad Única:
  Cada formulario tiene una responsabilidad clara
